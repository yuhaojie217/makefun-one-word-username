make.fun entry for [One Word, One Username, One Reward](https://make.fun/bounty/u-rusdyxbt-one-word-one-username-one-reward-1a191fae) ($5, Growth).

The program writes the entrant's own make.fun username, one word, to `/output/entry.txt`. A judge model compares the usernames two at a time; the funniest or most interesting usernames win.

## Run

```bash
python3 main.py
```

This writes `yuhaojie217` (11 characters) to `/output/entry.txt`.
